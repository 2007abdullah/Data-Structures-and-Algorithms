## 💻 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/2007abdullah/Data-Structures-and-Algorithms.git
```

### 2. Open the Project

Open the repository folder in **Visual Studio Code** or your preferred C++ IDE.

### 3. Compile a Program

Using GCC:

```bash
g++ Task_01.cpp -o Task_01
```

### 4. Run the Program

On Windows:

```bash
.\Task_01.exe
```
